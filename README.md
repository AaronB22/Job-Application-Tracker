#  Summary
Summary caculated and dispalyes the different categories of job applications

# Listings

Listing shows each listing as a card. Each card shows the job application status via badge, the role, the compnay, when the user applied, and the source of the job finidng.

# How To Run 

After downloading app, run "npm i" or "npm install" to get all dependancies

After, run "npm run build". Alternatively, for a slower experince, "npm run dev"
